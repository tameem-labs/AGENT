# DEVELOPMENT PROTOCOL

Every implementation AI follows:

1. Read root PROGRESS.md.
2. Identify current task.
3. Read PROJECT_MAP.md.
4. Read only relevant contracts/policies.
5. Inspect only relevant source.
6. Plan smallest safe change.
7. Implement.
8. Test.
9. Verify behavior and failure paths.
10. Update PROGRESS.md.
11. Stop.

Do not full-scan without need.
Do not random-refactor.
Do not silently change architecture.
Do not introduce major dependencies without justification.
Do not commit secrets.
Do not claim done without evidence.

If docs and code disagree, report the discrepancy instead of pretending.
